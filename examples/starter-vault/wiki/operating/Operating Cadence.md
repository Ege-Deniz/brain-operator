# Operating Cadence

The weekly rhythm. Customize to match how you actually work.

## Default rhythm

| Day | Block | What happens |
|-----|-------|--------------|
| Monday | Audit | `brain-evolve` runs (08:00) → `brain-ship` runs (09:00) → review the queue |
| Tuesday | Build | Deepest single-thread work block on the top priority |
| Wednesday | Build | Same |
| Thursday | Ship | Public-facing work: posts, drafts review, distribution |
| Friday | Reflect | Review log, update Project Triage, set next-week priority |
| Saturday | — | Open / off |
| Sunday | Reset | Skim wiki for staleness, fix obvious gaps, no new pages |

## Scoreboard (weekly)

Update only metrics that change behavior. Define your own. Examples:

- **Shipped artifacts** — pages, drafts, surfaces from this week
- **Money moves** — concrete progress on the income lane (sales calls, offers sent, revenue)
- **Public signal** — posts, repos pushed, comments / DMs received
- **Health floor** — sleep, training, food
- **Overdue decisions** — count of open decisions past deadline (should be 0)

## End-of-week ritual

1. Read `wiki/log.md` for the past 7 days. What got shipped? What got dropped?
2. Update `Project Triage`: anything still active, anything to pause, anything to kill?
3. Add one Decision Log entry if anything stuck or pivoted.
4. Queue next week's top single artifact in `_proposals/queue.md`.
